Work in Progress...

Preamble: Some other available solutions already exist to address the exact same problem as the one we are targeting here.
So, what's the point here? Good question.
Goals here are to:
  • Keep the size of the executable code as small as possible
  • Keep the Web Pages (and other related components) storage as tiny as possible
  • Keep the client(s) independent of any extra software to install
  • Keep the runtime energy consumption as small as possible
  • Keep the cost of the hardware as low as possible
  • Keep it as compliant as possible with existing standards (vast topic!), to allow communication with the outside world

Alors, quel est l'intérêt de ce qu'on montre ici ? Bonne question.
Les objectifs sont de :
  • Réduire au maximum la taille du code exécutable
  • Minimiser l'espace de stockage des pages web (et des composants associés)
  • Rendre le(s) client(s) indépendant(s) de tout logiciel supplémentaire à installer
  • Réduire au maximum la consommation d'énergie lors de l'exécution
  • Maintenir le coût du matériel aussi bas que possible.
  • Rester aussi conforme que possible aux normes existantes (vaste sujet !), afin de permettre la communication avec l'extérieur.
