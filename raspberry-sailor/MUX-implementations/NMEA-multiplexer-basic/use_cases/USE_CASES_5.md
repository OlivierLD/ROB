### Context
The Raspberry Pi emits its own network, and is connected to the boat's electronic (ShipModul or so).  
Data can be visualized on the screen connected to the Raspberry Pi, or from any network-aware device, with a (recent) browser.  
The Raspberry Pi is strong enough to host programs like [OpenCPN](https://opencpn.org/).  
The Multiplexer (options to be defined) is also running on the Raspberry Pi.  
An OS like [Twister OS](https://twisteros.com/) is a very good option.

Adapters (power supply, HDMI sockets, serial/USB ports) and SD Card have to be provided as well.
