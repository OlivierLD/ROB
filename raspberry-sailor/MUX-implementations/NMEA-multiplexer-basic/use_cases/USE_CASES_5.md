---

The Raspberry Pi emits its own network, and is connected to the boat's electronic (ShipModul or so).  
The Raspberry Pi is strong enough to host programs like OpenCPN.  
The Multiplexer (options to be defined) is also running on the Raspberry Pi.  
An OS like [Twister OS](https://twisteros.com/) is a very good option.
